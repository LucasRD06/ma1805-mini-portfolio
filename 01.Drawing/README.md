This first small project is fully focused on drawing in JavaScript. For this project, I used basic shapes of circles and triangles to create an emoji-inspired image. This involves identifying the correct measurements for the shapes and continuously testing them. Once I had identified the best positions and sizes for all of the shapes to create a face, I then decided on what colours I wanted the shapes to be, using the fill technique in JavaScript. This resulted in a unique emoji, by only using simple shapes and colours.
