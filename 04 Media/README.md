This final small project, which is focused on bringing media into JavaScript, is inspired by Nike adverts. I have integrated 2 images into this project. One of which is of a Nike project, and the other is an image of text using the 'Cooper Black' font in a bright orange colour; these are to show the capabilities of media in JavaScript projects. To make this small project into something creative, I decided to try to make this into what might seem like an advert. I used techniques from the previous projects in this one. Firstly, I created a blue background which would be seen around both images. I then created moving text at the bottom of the image of the Nike slogan that continuously repeats itself. The images are then integrated into the image above the text, one displaying a Nike product and the other being the text showing that this is uploaded media. 
I think this final project shows that the methods used in JavaScript give us the tools to create very creative ideas which can appeal to a wide range of people.
